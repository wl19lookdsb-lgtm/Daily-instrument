# Z-Library 划词中文翻译

适用于 Microsoft Edge 的 Manifest V3 扩展。在已启用的网站上选中文字，自动弹出简体中文译文。当前版本 **1.1.0**。

## 翻译记录与单词排名

在扩展面板点击“翻译记录与单词排行”，打开独立记录网页。可搜索原文、译文、来源网站，删除记录或导出全部记录为 JSON。该页面无需服务器，数据仅保存在此浏览器中，不跨设备同步。

所有成功翻译（包括命中缓存的查询）保存为记录；只有单独查询的英文词参与排行。忽略大小写及首尾标点，支持英文撇号、连字符，不合并不同词形。段落不拆词，失败请求不计数。保留最近 1500 条记录，排行榜由这些记录计算，删除记录也会减少对应词的次数。

更新时请用新版扩展目录中的文件覆盖旧目录，在扩展管理页点击重新加载，再刷新阅读网页。不要卸载，以保留现有网站设置及以后积累的记录。历史只从新版启用后开始保存，不会恢复旧版查询。

## 功能

- 自动识别源语言，翻译为简体中文。
- 按网站启用，适应不同阅读域名。
- 支持同源嵌入阅读框架及继承来源的阅读框架。
- 在阅读器批注菜单修改选区之前捕获文字。
- 支持重试、Esc 关闭及最多 3000 字符的段落翻译。
- 无构建步骤，无第三方运行时依赖。

## 安装

1. 下载本仓库 ZIP 并解压，或克隆仓库。
2. 打开 Edge 的 `edge://extensions`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择本仓库内的 **`zlibrary-translator` 子文件夹**，该目录中有 `manifest.json`。
4. 打开实际使用的阅读页面，点击扩展图标，再点击“同意并在当前网站启用”。
5. 刷新阅读页面，选中文字即可翻译。

网站首页和阅读器可能位于不同子域名，需要在**阅读页面所在域名**启用。详细说明见 [使用说明](zlibrary-translator/使用说明.md)。

## 隐私与限制

启用后，所选文字会发送到 Google 翻译的无需密钥非官方接口；需网络能访问 `translate.googleapis.com`。该接口可能限流、变化或停止提供服务，没有长期可用性保证。

翻译请求不附带整页内容、页面地址或站点 Cookie。后台只在内存缓存最多 80 条结果，本地持久保存启用的网站列表及最近 1500 条翻译历史。历史的来源地址移除查询参数和片段，不发送给翻译服务。服务方仍能看到所选文字及网络请求信息。卸载扩展可能删除本地数据，请定期导出。

不支持浏览器内置 PDF 阅读器、输入框或编辑区。独立跨域 iframe 需要单独授权，受沙箱限制的阅读器不保证兼容。本项目与 Z-Library、Google、Microsoft 没有官方关联。

## 开发与验证

使用 Node.js 20 或更新版本，在仓库根目录运行：

```sh
npm test
```

测试覆盖后台翻译结果解析、缓存、来源校验、长度限制、网络及 HTTP 错误、请求合并，以及阅读器清除选区时的文字捕获。测试使用模拟环境，不代表所有阅读器或真实翻译网络均已验证。用户已确认 1.0.1 在其使用环境中成功工作。

修改后在 Edge 扩展管理页点击重新加载，再刷新阅读页面。

## 文件结构

```text
zlibrary-translator/                    # 加载到 Edge 的扩展目录
  manifest.json
  background.js                        # 翻译请求、校验与缓存
  content.js                           # 选词捕获及译文弹窗
  popup.html / popup.css / popup.js     # 网站启用面板
  使用说明.md
zlibrary-translator-tests.cjs           # 后台逻辑测试
zlibrary-translator-selection-tests.cjs # 选区兼容测试
```
