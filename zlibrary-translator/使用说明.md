# Z-Library 划词中文翻译

## 安装到 Microsoft Edge

1. 如果下载的是 ZIP，先解压，保留整个文件夹。
2. 在 Edge 地址栏输入 `edge://extensions`。
3. 打开“开发人员模式”，点击“加载解压缩的扩展”。
4. 选择包含 `manifest.json` 的 `zlibrary-translator` 文件夹。
5. 打开你平时使用的 Z-Library 网页，点击 Edge 工具栏的扩展图标，找到“Z-Library 划词中文翻译”。
6. 点击“同意并在当前网站启用”，接受 Edge 的网站权限提示。
7. 鼠标选中书名、简介等文字，松开后自动显示简体中文翻译。支持键盘 Shift + 方向键选取。

点击弹窗外部、× 或按 Esc 关闭。翻译失败可点击“重试”。在扩展面板点击“停用当前网站”即可停止划词翻译。

## 网站与权限

不预置 Z-Library 域名，避免域名变更导致失效，也不推荐任何镜像。只需在你已经使用的网站上启用。换域名或跳转到其他子域名后，需要为新网站再启用一次。

扩展按授权网站注册脚本，重启浏览器后仍有效。当前已打开的其他标签页需要刷新。1.0.1 支持已授权网站的同源 iframe 及继承来源的 about:blank/srcdoc 阅读框架，并在阅读器批注菜单修改选区之前保存所选文字。不处理输入框、编辑区域、浏览器内置 PDF 阅读器。独立跨域 iframe 仍需要单独授权，受沙箱限制的阅读器尚不保证兼容。

从 1.0.0 更新：用新文件替换原加载目录中的文件，在 Edge 扩展管理页重新加载插件，再刷新阅读页面。也可以移除旧版后加载新文件夹，重新启用当前阅读网站。

停用后，已注入的脚本会停止处理选词，刷新页面后不再加载。Edge 保留曾授予的访问权限；可在扩展详情中撤销，或卸载扩展以彻底移除。

## 翻译服务与隐私

使用 Google 翻译的无需密钥非官方接口，目标语言为简体中文，源语言自动检测。这不是 Google 官方支持的商业 API，无法保证长期可用，可能受网络、限流和接口变更影响。需要浏览器能访问 `translate.googleapis.com`。

启用后，选中的文字会自动发送到 Google。请求不附带网页地址、整页内容、站点 Cookie 或登录信息，但服务方仍能看到网络请求及所选文字。请勿选取需要保密的内容。单次最多 3000 字符。

扩展不保存翻译历史，只在后台内存中缓存最近最多 80 条结果；后台休眠后缓存消失。本地只保存启用的网站列表。没有统计或广告代码。

## 常见问题

- **无法连接 / 超时**：检查网络能否访问 Google 翻译，稍后点击重试。
- **没有弹窗**：确认当前域名已启用，刷新网页，再选中正文。Edge 内置页面无法注入扩展。
- **扩展更新后不工作**：在 `edge://extensions` 点击扩展的重新加载按钮，再刷新目标网页。
- **选中文字过长**：分段选取，每段不超过 3000 字符。
